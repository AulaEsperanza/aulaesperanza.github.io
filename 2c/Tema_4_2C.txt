<section id="prensa"><h2>La prensa y otros medios</h2><p>Los textos del ámbito social circulan en espacios públicos como los medios de comunicación y las redes. Pueden informar, interpretar hechos o persuadir.</p>
<div class="grid"><div class="card"><h3>Prensa escrita y audiovisual</h3><p>La prensa difunde mensajes escritos en periódicos y revistas, en papel o en formato digital. Los medios audiovisuales, como un telediario, combinan imagen y sonido. La radio transmite la información mediante el sonido.</p></div><div class="card"><h3>Generalista y especializada</h3><p>La prensa generalista o no especializada trata asuntos variados y se dirige a un público amplio. La especializada se centra en un ámbito, como deportes, moda o ciencia.</p></div><div class="card"><h3>Ediciones digitales</h3><p>Un periódico digital puede actualizar las noticias, enlazar documentos e incorporar vídeos, audios y galerías. En Internet, los medios pueden ofrecer secciones específicas, como una cobertura en directo, un espacio de verificación o una sección de contenidos multimedia.</p></div></div></section>
<section id="noticia"><h2>La noticia</h2><p>Es el relato breve de un suceso reciente y de interés para el público. Se organiza en <strong>titular, entrada y cuerpo</strong>.</p>
<div class="grid"><article class="sample accent"><div class="eyebrow">Ejemplo ficticio</div><p><span class="label">Antetítulo</span>Vida escolar</p><h3><span class="label">Título</span>El instituto abre la biblioteca durante el recreo</h3><p><span class="label">Subtítulo</span>El servicio funcionará tres días a la semana.</p><p><span class="label">Entrada</span>El IES del Faro abrió este lunes su biblioteca durante el recreo para que el alumnado pueda leer y tomar libros prestados.</p><p><span class="label">Cuerpo</span>La biblioteca abrirá los lunes, miércoles y viernes. El préstamo se registrará en el mostrador y los libros podrán devolverse en un plazo de dos semanas.</p><p>El espacio cuenta con una mesa de novedades junto a la entrada.</p></article>
<div class="card"><h3>Titular</h3><p>Presenta el asunto. El <strong>título</strong> expresa lo principal. El <strong>antetítulo</strong> puede situar el tema y el <strong>subtítulo</strong> puede ampliar un dato.</p><h3>Entrada o entradilla</h3><p>El primer párrafo resume lo esencial. Puede responder a las preguntas <strong>qué, quién, cuándo, dónde, cómo y por qué</strong>, según los datos disponibles.</p><h3>Cuerpo</h3><p>Amplía la información con detalles, antecedentes o declaraciones. En la <strong>pirámide invertida</strong>, los datos se presentan en orden decreciente de importancia.</p><div class="pyramid" aria-label="Orden decreciente de importancia"><div>Hecho principal</div><div>Datos esenciales</div><div>Detalles y contexto</div><div>Datos secundarios</div></div></div></div></section>
<section id="generos"><h2>Entrevista, crónica y reportaje</h2><div class="grid"><div class="card"><h3>Entrevista</h3><p>Género dialogado que suele organizarse en preguntas y respuestas. Permite conocer las opiniones o la experiencia de un personaje público o de alguien relacionado con un hecho de interés.</p><p><strong>Pista.</strong> ¿Quién pregunta y quién responde?</p></div><div class="card"><h3>Crónica</h3><p>Narra hechos de una jornada, un partido u otro acontecimiento. Combina información con observaciones o valoraciones de quien lo cuenta. Puede seguir el orden en que sucedieron los hechos.</p><p>El <strong>corresponsal</strong> informa habitualmente desde un lugar. El <strong>enviado especial</strong> se desplaza para cubrir un acontecimiento concreto.</p></div><div class="card"><h3>Reportaje</h3><p>Texto generalmente más extenso que profundiza en un tema. Aporta contexto, datos y declaraciones de expertos y protagonistas. Combina información con interpretación y puede recoger opiniones atribuidas a sus fuentes.</p><p><strong>Pista.</strong> ¿Qué fuentes y datos ayudan a entender el tema?</p></div></div></section>
<section id="redes"><h2>Redes sociales y netiqueta</h2><p>Son comunidades interactivas de usuarios que intercambian información y contenidos a través de plataformas digitales.</p><div class="grid"><div class="card"><h3>Usos</h3><ul><li><strong>LinkedIn</strong> · contactos y contenidos profesionales.</li><li><strong>X (antes Twitter)</strong> · mensajes breves y conversaciones sobre actualidad.</li><li><strong>YouTube</strong> · vídeos, tutoriales y directos.</li><li><strong>Instagram</strong> · fotos, vídeos e historias.</li><li><strong>TikTok</strong> · vídeos breves, tendencias y divulgación.</li></ul></div><div class="card"><h3>Veracidad y privacidad</h3><p>Un <strong>bulo</strong> es una información falsa difundida como si fuera cierta. Un <strong>ciberanzuelo</strong> busca que hagas clic mediante un titular exagerado o intrigante. Antes de compartir, comprueba quién lo publica, cuándo y qué pruebas aporta. Contrasta con otra fuente fiable.</p><p>Protege tus datos y tu ubicación, revisa quién puede ver tus publicaciones y pide permiso antes de compartir imágenes de otras personas.</p></div><div class="card"><h3>Etiqueta digital</h3><p>La <strong>netiqueta</strong> reúne normas de convivencia en línea.</p><ul><li>Evita comentarios ofensivos y respeta las opiniones ajenas.</li><li>Usa un lenguaje claro, correcto y adecuado al contexto.</li><li>Evita mensajes irrelevantes y solicitudes de amistad o invitaciones no deseadas.</li></ul></div></div></section>
<section id="publicidad"><h2>Publicidad y propaganda</h2><p>Los mensajes persuasivos intentan influir en lo que hacemos o pensamos. Para distinguirlos, fíjate en su <strong>finalidad principal</strong>.</p><div class="grid"><div class="card"><h3>Publicidad</h3><p>Promociona un producto, un servicio o una acción. Suele destacar un beneficio e incluir una llamada a actuar, como comprar, inscribirse o visitar un lugar.</p></div><div class="card"><h3>Propaganda</h3><p>Difunde ideas políticas, ideológicas, religiosas o sociales para conseguir adhesión o influir en la conducta. Suele recurrir a lemas, símbolos y apelaciones a valores o emociones.</p></div></div><br>

<div class="card" id="anatomia" hidden><h3>Partes del anuncio</h3><ul><li><strong>Título</strong> · «Mercadillo de moda circular» presenta la actividad.</li><li><strong>Eslogan</strong> · «Dale otra vuelta a tu ropa» es una frase breve y memorable.</li><li><strong>Marca</strong> · Vuelta identifica a quien organiza y firma el anuncio.</li><li><strong>Logotipo</strong> · VUELTA es la representación gráfica del nombre.</li><li><strong>Símbolo</strong> · La flecha circular es el signo visual asociado a la marca.</li><li><strong>Imagen</strong> · Las prendas muestran de qué trata el mercadillo.</li></ul></div></div></section>

<section id="trabajo"><h2>Trabajo · La redacción de 2.º C</h2><div class="card accent"><p><strong>En parejas, preparad una página de periódico escolar.</strong> Elegid un hecho reciente del centro o del barrio que podáis comprobar. Podéis trabajar con un caso inventado si lo identificáis como simulación y usáis fuentes ficticias claramente señaladas.</p>
<ol class="steps"><li><strong>Recoged datos.</strong> Anotad qué ocurrió, quién participó, cuándo y dónde. Contrastad dos fuentes, por ejemplo, un aviso del centro y el testimonio de una persona participante.</li><li><strong>Redactad la noticia.</strong> Escribid título, entrada y cuerpo de dos o tres párrafos. Colocad primero lo más importante. Podéis añadir antetítulo y subtítulo.</li><li><strong>Añadid otra pieza.</strong> Elegid una entrevista de tres preguntas con sus respuestas, una crónica breve de la jornada o un minirreportaje con contexto y dos fuentes identificadas.</li><li><strong>Preparad la difusión.</strong> Redactad un mensaje breve para anunciar vuestra noticia en una red social simulada. Usad un lenguaje respetuoso y evitad datos privados o imágenes sin permiso.</li></ol><p><strong>Entrega.</strong> Una página en papel o en formato digital con la noticia, la segunda pieza, el mensaje para redes y las fuentes al pie.</p></div>
<div class="card" style="margin-top:1rem"><h3>Cómo se valorará</h3><ul><li><strong>4 puntos</strong> · Estructura de la noticia y orden de la información.</li><li><strong>2 puntos</strong> · Rasgos del segundo género elegido.</li><li><strong>2 puntos</strong> · Datos comprobables y fuentes identificadas.</li><li><strong>2 puntos</strong> · Claridad, corrección, privacidad y netiqueta.</li></ul><button class="print" onclick="window.print()">Imprimir la ficha del trabajo</button></div></section>

const byId = (id) => document.getElementById(id);
let index = 0;
let points = 0;
let answered = false;
const progress = byId('progress');
progress.max = items.length;
function updateScore() {
  byId('score').textContent = 'Aciertos: ' + points;
  progress.value = index + Number(answered);
}
function showRound(focus = false) {
  answered = false;
  byId('round').hidden = false;
  byId('next').hidden = true;
  byId('restart').hidden = true;
  byId('feedback').textContent = '';
  byId('position').textContent = 'Reto ' + (index + 1) + ' de ' + items.length;
  updateScore();
  const [question, excerpt, options] = items[index];
  byId('question').textContent = question;
  byId('excerpt').textContent = excerpt;
  byId('choices').replaceChildren();
  options.forEach((option, choice) => {
    const button = document.createElement('button');
    button.type = 'button';
    button.textContent = option;
    button.addEventListener('click', () => checkAnswer(choice));
    byId('choices').append(button);
  });
  if (focus) byId('question').focus();
}
function checkAnswer(choice) {
  if (answered) return;
  answered = true;
  const [, , options, correct, explanation] = items[index];
  if (choice === correct) points++;
  updateScore();
  const buttons = byId('choices').children;
  buttons[choice].dataset.result = 'bad';
  buttons[correct].dataset.result = 'ok';
  byId('feedback').textContent = (choice === correct ? 'Correcto. ' : 'Respuesta correcta: ' + options[correct] + '. ') + explanation;
  byId('next').textContent = index + 1 === items.length ? 'Ver resultado' : 'Siguiente texto';
  byId('next').hidden = false;
  byId('next').focus();
  for (const button of buttons) button.disabled = true;
}
byId('next').addEventListener('click', () => {
  index++;

  byId('position').textContent = 'Juego completado';

  byId('restart').hidden = false;

});

});
