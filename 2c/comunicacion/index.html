💬 La comunicación
y las funciones del lenguaje

¿Quién habla? ¿A quién? ¿Qué quiere conseguir? Descubre cómo funciona cualquier acto de comunicación y qué función del lenguaje predomina en cada mensaje.

💬 Elementos 🎯 Funciones 🔗 Relación 🎮 Practica ⚡ Reto de clase

1. Los elementos de la comunicación

En cualquier acto comunicativo intervienen varios elementos. Para comprender bien un mensaje debemos saber quién lo produce, quién lo recibe, qué transmite y en qué circunstancias se produce.

💡 Idea clave: en un acto comunicativo aparecen todos estos elementos. Después veremos que las funciones del lenguaje se relacionan con el elemento sobre el que recae especialmente la intención comunicativa.
🗣️

Emisor

Es quien produce y transmite el mensaje.

Lucía dice: «Estoy muy contenta».
👂

Receptor

Es quien recibe e interpreta el mensaje.

Marcos escucha lo que dice Lucía.
💌

Mensaje

Es la información que el emisor transmite.

«Mañana tenemos examen».
🔤

Código

Es el sistema de signos y reglas utilizado para comunicarnos.

El castellano, la lengua de signos, el código Morse…
📡

Canal

Es el medio físico por el que circula el mensaje.

El aire, el papel, el teléfono, Internet…
🌍

Contexto o referente

Es la realidad, situación o asunto al que se refiere el mensaje.

Una conversación sobre el tiempo de mañana.

2. Las funciones del lenguaje

Cuando hablamos no siempre perseguimos el mismo objetivo. Podemos informar, expresar sentimientos, pedir algo, comprobar que nos escuchan, hablar de la lengua o cuidar especialmente la forma del mensaje.

❤️

Expresiva o emotiva

El emisor expresa emociones, sentimientos, opiniones o estados de ánimo.

«¡Qué alegría verte!»
👉

Apelativa o conativa

Busca influir en el receptor o provocar una respuesta.

«Cierra la ventana, por favor».
📰

Representativa o referencial

Sirve para transmitir información sobre la realidad.

«El agua hierve a 100 °C a nivel del mar».
📞

Fática

Sirve para iniciar, mantener, comprobar o cerrar el canal de comunicación.

«¿Me oyes?»
🔤

Metalingüística

Utilizamos el lenguaje para hablar del propio lenguaje.

«“Árbol” es un sustantivo».
✨

Poética

La atención se dirige especialmente hacia la forma del mensaje.

«La luna borda de plata el mar».

3. La conexión que tienes que recordar

No memorices dos listas separadas. Cada función destaca especialmente uno de los elementos de la comunicación.

🗣️
EMISOR
↔ EXPRESIVA / EMOTIVA
👂
RECEPTOR
↔ APELATIVA / CONATIVA
🌍
CONTEXTO / REFERENTE
↔ REPRESENTATIVA / REFERENCIAL
📡
CANAL
↔ FÁTICA
🔤
CÓDIGO
↔ METALINGÜÍSTICA
💌
MENSAJE
↔ POÉTICA
🧠 Truco para entenderlo:
Pregúntate siempre: «¿Dónde está puesta principalmente la atención?»
¿En quien habla? ¿En quien escucha? ¿En la realidad? ¿En comprobar el contacto? ¿En el código? ¿O en cómo está construido el mensaje?

4. Practica: ¿qué función predomina?

Lee cada mensaje y selecciona la función predominante. Después comprueba tus respuestas.
